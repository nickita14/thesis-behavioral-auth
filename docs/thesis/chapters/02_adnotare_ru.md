# АННОТАЦИЯ

**МИРОНОВ НИКИТА.** Использование AI поведенческого анализа для аутентификации транзакций и предотвращения phishing-атак. Магистерская работа. Кишинёв, 2026.

Работа включает введение, 4 главы, заключение, библиографию из 19 источников. Общий объём: 89 страниц основного текста, 5 рисунков, 9 таблиц.

**Ключевые слова:** поведенческая биометрия, аутентификация транзакций, обнаружение phishing-атак, машинное обучение, Isolation Forest, XGBoost, risk-based аутентификация, динамика нажатий клавиш.

**Цель и задачи работы.** Целью настоящей работы является разработка исследовательского web-прототипа системы risk-based аутентификации транзакций, объединяющей ML-классификацию URL и поведенческий анализ пользователя для формирования объяснимого решения (ALLOW / CHALLENGE / DENY) по каждой операции. Для достижения цели решены следующие задачи: проектирование модульной архитектуры с соблюдением принципов SOLID; реализация per-user поведенческого pipeline из 16 признаков; реализация phishing detector на основе XGBoost с 30 признаками URL; реализация механизма принятия решений RiskDecisionEngine; валидация поведенческой подсистемы на стандартном benchmark; acceptance-тестирование с реальными пользователями и документирование известных ограничений системы.

**Методология исследования.** Система реализована на стеке Django 5.1, Django REST Framework и PostgreSQL (backend), React 19 с TypeScript и Vite (frontend). Поведенческий анализ построен на алгоритме Isolation Forest — методе one-class anomaly detection, формирующем индивидуальный профиль пользователя из 16 временны́х и динамических признаков, извлекаемых по повторениям с помощью алгоритма Тьюки. Phishing detection использует классификатор XGBoost, обученный на 30 лексических и хост-ориентированных признаках URL. Валидация проведена на CMU Keystroke Dynamics Benchmark [KILLOURHY & MAXION 2009] по методологии Leave-One-Subject-Out (LOSO). Обученные модели сериализуются через joblib.

**Научная новизна и оригинальность.** Предложена и реализована гибридная risk-based архитектура, в которой phishing detection и поведенческая биометрика применяются как взаимодополняющие сигналы в едином механизме принятия решений. Разработан challenge-typing механизм для решения проблемы несоответствия домена обучения и инференса: пользователь вводит одну и ту же эталонную фразу как при enrollment, так и при выполнении транзакций, что обеспечивает идентичный входной домен. Проведена воспроизводимая cross-user валидация на стандартном benchmark и задокументированы граничные случаи системы, включая паттерн hunt-and-peck typing как case study.

**Решённая проблема.** Классические методы аутентификации — парольная и многофакторная — подтверждают знание секрета или владение устройством, но не гарантируют, что текущий оператор устройства является легитимным владельцем аккаунта. При phishing-атаке пользователь может быть обманут и передать доступ злоумышленнику. Работа решает эту проблему через непрерывную оценку риска на основе поведенческого профиля пользователя и контекста операции.

**Теоретическое значение работы.** В работе систематизированы подходы поведенческой биометрики, phishing detection и адаптивной аутентификации в рамках единой концептуальной модели risk-based оценки транзакций. Результаты валидации поведенческой подсистемы — EER (Equal Error Rate) 14,4% и AUC ROC 0,916 на CMU Benchmark — сопоставимы с литературными значениями для Isolation Forest [KILLOURHY & MAXION 2009], а точность phishing detector 97,24% на UCI Phishing Websites Dataset соответствует опубликованным показателям для аналогичных наборов признаков [MOHAMMAD et al. 2014].

**Прикладная ценность работы.** Реализованы 277 автоматических тестов, охватывающих все публичные API endpoints, ML-интерфейсы и логику принятия решений. Работающий прототип демонстрирует полный end-to-end цикл защиты транзакций и может служить основой для дальнейших исследований в области поведенческой биометрии и адаптивной аутентификации, а также отправной точкой для адаптации к реальным банковским системам, e-commerce и fintech-приложениям.
