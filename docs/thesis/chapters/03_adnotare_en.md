# ABSTRACT

**MIRONOV Nichita.** Using behavioral AI analysis for transaction authentication and phishing prevention. Master's thesis. Chișinău, 2026.

The thesis includes an introduction, 4 chapters, a conclusion, and a bibliography of 19 sources. Total volume: 89 pages of main text, 5 figures, 9 tables.

**Keywords:** behavioral biometrics, transaction authentication, phishing detection, machine learning, Isolation Forest, XGBoost, risk-based authentication, keystroke dynamics.

**Aim and objectives.** The aim of this thesis is to develop a research web prototype of a risk-based transaction authentication system that combines ML-based URL classification with user behavioral analysis to produce an explainable verdict (ALLOW / CHALLENGE / DENY) for each operation. The objectives include: designing a modular architecture adhering to SOLID principles; implementing a per-user behavioral pipeline with 16 features; implementing an XGBoost-based phishing detector with 30 URL features; implementing the RiskDecisionEngine decision mechanism; validating the behavioral subsystem on a standard benchmark dataset; conducting acceptance testing with real users; and documenting known system limitations.

**Research methodology.** The system is implemented using Django 5.1, Django REST Framework, and PostgreSQL (backend), React 19 with TypeScript and Vite (frontend). Behavioral analysis is built on Isolation Forest — a one-class anomaly detection algorithm that constructs an individual user profile from 16 temporal and dynamic features extracted per-repetition via Tukey's fence adaptive boundary detection. Phishing detection uses an XGBoost classifier trained on 30 lexical and host-based URL features. Cross-user validation is performed on the CMU Keystroke Dynamics Benchmark [KILLOURHY & MAXION 2009] using Leave-One-Subject-Out (LOSO) methodology. Trained models are serialized with joblib.

**Scientific novelty and originality.** A hybrid risk-based architecture is proposed and implemented in which phishing detection and behavioral biometrics serve as complementary signals within a unified decision engine. A challenge-typing mechanism is developed to address the training/inference domain mismatch problem: users type the same reference phrase during enrollment and during transaction authentication, ensuring an identical input domain. Reproducible cross-user validation is performed on a standard benchmark dataset, and boundary cases of the system are documented — including the hunt-and-peck typing pattern as a case study for out-of-distribution behavior.

**Problem solved.** Classical authentication methods — password and multi-factor authentication — confirm knowledge of a secret or possession of a device but do not guarantee that the current device operator is the legitimate account owner. During a phishing attack, the user may be deceived into granting access to an attacker. This thesis addresses the problem through continuous risk assessment that combines the user's behavioral profile with the context of the operation being performed.

**Theoretical significance.** The thesis systematizes approaches to behavioral biometrics, phishing detection, and adaptive authentication within a unified conceptual model of risk-based transaction evaluation. The behavioral subsystem validation results — EER (Equal Error Rate) of 14.4% and AUC ROC of 0.916 on the CMU Benchmark — are consistent with published baseline values for Isolation Forest [KILLOURHY & MAXION 2009]. The phishing detector accuracy of 97.24% on the UCI Phishing Websites Dataset is consistent with published results for comparable feature sets [MOHAMMAD et al. 2014].

**Practical value.** A total of 277 automated tests were implemented, covering all public API endpoints, ML interfaces, and decision logic. The working prototype demonstrates a complete end-to-end transaction protection cycle and can serve as a foundation for further research in behavioral biometrics and adaptive authentication, as well as a reference implementation for adaptation to real-world banking systems, e-commerce platforms, and fintech applications.
